# Shaft — direção visual futura

## Intenção

Desenvolver futuramente uma identidade visual própria para o Shaft, preservando a simplicidade e a legibilidade atuais.

## Direção estética

- Referências vitorianas e steampunk.
- Engrenagens e elementos mecânicos usados com moderação.
- Composição minimalista, sem excesso de ornamentação.
- Manter a paleta atual: fundo escuro, coral e tons claros de apoio.
- Preservar o caráter editorial das letras, semelhante à tipografia de livros já usada no aplicativo.

## Possível evolução do produto

Depois de amadurecer a identidade e validar a versão pessoal, considerar uma edição pública e gratuita do Shaft. Essa versão poderá servir como primeiro projeto público para ingressar no desenvolvimento e na publicação de produtos digitais.

## Limite desta etapa

Esta é apenas uma direção registrada para discussão futura. A publicação privada atual não deve receber um redesign steampunk antes de uma decisão específica sobre essa fase.
